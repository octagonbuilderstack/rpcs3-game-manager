## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Game Library** | Organize your PS3 library with box art and compatibility info |
| **Config Profiles** | Save CPU, GPU and audio settings per game or globally |
| **Patch Manager** | Enable and disable RPCS3 community patches per title |
| **Quick Launch** | Launch any game with its saved profile in one click |
